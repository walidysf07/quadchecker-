                        
                         QuadChecker 

                                        __________________________________________________________






program is a quad detector: it reads a rectangle made of characters and determines whether it was generated by quadA, quadB, quadC, quadD, or quadE.




 
             INPUT
               │
               ▼
        Read from stdin
               │
               ▼
       Find width (w)
               │
               ▼
       Find height (h)
               │
               ▼
       Validate input
               │
               ▼
       ┌───────────────┐
       │               │
       ▼               ▼
    check A          check B
       │               │
       ▼               ▼
    check C          check D
       │               │
       └───────┬───────┘
               ▼
            check E
               │
               ▼
       Print all matches
               │
               ▼
       If none → "Not a
          quad function"

func check(s []byte, w, h int, a, b, c, d, x, y byte) bool {


"Does this input exactly match this particular quad pattern?"


s → the input
w → width
h → height
a → top-left character
b → top-right character
c → bottom-left character
d → bottom-right character
x → top/bottom border character
y → left/right border character




For every row
    For every column
        Determine what character SHOULD be here
                    │
                    ▼
        Compare with actual character
                    │
             ┌──────┴──────┐
             │             │
          different      same
             │             │
             ▼             ▼
          false       continue
                           │
                           ▼
                    all characters
                       checked
                           │
                           ▼
                         true



___________________________________________________________________________________



Read everything from standard input.

If there is no input, say "Not a quad function."

Find how many visible characters are on the first line. That's the width.

Count how many newline characters there are. That's the height.

Make sure the input has exactly the expected number of characters.

Then check the input against quadA's pattern.

If it matches, print quadA.

Then check against quadB.

If it matches, print quadB.

Then check quadC, quadD and quadE.

If multiple patterns match, separate their names with ||.

If nothing matches, print "Not a quad function."

        i →

    │ A  X  X  X  B │  ← j = 0
    │ Y           Y │
    │ Y           Y │
    │ C  X  X  X  D │  ← j = h-1
    └───────────────┘





Am I A? → use a
Am I B? → use b
Am I C? → use c
Am I D? → use d
Am I on top/bottom? → use x
Am I on left/right? → use y
Otherwise → use space

   checked everything?
